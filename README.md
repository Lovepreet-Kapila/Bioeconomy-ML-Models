Iris Dataset Analysis with NumPy
This notebook demonstrates foundational data analysis techniques using NumPy on the classic Iris dataset. It’s part of my data exploration series for machine learning applications in bioeconomy.

Objectives
- Load and inspect the Iris dataset
- Perform statistical analysis on sepal length
- Calculate mean, median, standard deviation, and percentiles
- Interpret results to understand data distribution

Tech Stack
- Language: Python 3
- Libraries: NumPy, Matplotlib (optional for visualization)
- Tools: Jupyter Notebook

Key Insights
- Mean Sepal Length: ~5.84
- Median Sepal Length: ~5.8
- Standard Deviation: ~0.83
- 95th Percentile: ~7.25
These metrics help understand the spread and central tendency of the sepal length feature, which is critical for feature engineering and model training.

- Importance of statistical metrics in understanding feature distributions
